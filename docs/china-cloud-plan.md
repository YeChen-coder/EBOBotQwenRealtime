# 迁移到国内云服务器：计划书

> 2026-11-08 起草。还没开始改代码。价格来自第三方文章，下单前用官网或 `aliyun` 命令查实时价。

## 0. 为什么要搬

- 程序跑在多伦多：机器人在国内，千问在阿里云北京，每一句话都要跨境来回两趟。
- 2026-11-08 实测：北京时间晚上 17:00 以后，多伦多到阿里云北京的上传速度被限到约 35 KB/s。实时语音识别至少要约 43 KB/s，结果识别越积越慢，看板上全是 "No transcript within 8s; ignoring turn"，机器人等于不理人。而晚上正是家里人用得最多的时候。
- 放在家人电脑上不现实：家里人可能随手关机，也没法远程维护。
- 搬到北京以后：机器人、程序、千问都在国内，跨境限速影响不到对话本身。跨境的只剩我们这边 SSH 维护，慢一点也没关系。

## 1. 需要什么配置（按现在的实际占用推算）

2026-11-08 在本机用 `docker stats` 测的（Engine 已连续运行 7.9 天）：

| 容器 | CPU（1.0 = 一个核） | 内存 | 说明 |
|---|---|---|---|
| assistant | 约 0.1 | 1.5 GB | 待机唤醒时本地 Whisper small 会短暂吃满几个核 |
| ebo-engine | 约 0.55 | 0.35 GB | 机器人音视频收发（Agora） |
| frigate | 约 0.07 + 显卡 | 2.1 GB | 现在解码和检测都在 RTX 4070 SUPER 上 |
| mosquitto | ≈0 | 很小 | |

- **改成 CPU 以后**：Frigate 要自己解码 640×360、每秒 5 帧，再跑 YOLOv9-s-320 和人脸识别，估计还要多 1–1.5 个核。
- **合计**：平时 2–2.5 个核、4–5 GB 内存，Whisper 转录时短时间冲高。
- **4 核 8G 最稳，硬盘 60–80 GB**（镜像约 6 GB，data 目录约 0.9 GB）。
- **2 核 4G 也很有希望**，前提是先瘦身：
  - 把多个容器合成一两个**省不了内存**：容器本身几乎不占内存，内存是里面的程序用的。
  - Frigate 改 CPU 本身就省内存。现在的检测进程占 1.1 GB，主要是加载了 CUDA 运算库；CPU 版估计 200–300 MB，能省约 800 MB。
  - Whisper small 换 base 能再省几百 MB。
  - 瘦身后估计总共 2.5–3.3 GB。实验时在 4 核 8G 的机器上用 Docker 把整套限制在 2 核 4G 里跑一晚，能跑住就买 2 核 4G。
  - assistant 里那份 YOLO（找人转圈时用）不要去掉：它专门用来补 Frigate 漏掉的沙发上不动的人，也只占一两百 MB。
- **必须是 x86（amd64）**：Engine 里的 Agora SDK 只有 x86 版本，便宜的 ARM 机型不能用。
- **不要带显卡的机型**：月费 ¥1000 起，不值。
- **不要"突发性能"类机型**（阿里云 t5/t6 这类）：Frigate 一天 24 小时持续占 CPU，积分很快耗完，然后就卡死。
- **网络**：机器人发来的音视频平均约 1.5 Mbps（7.9 天收了 132 GB），阿里云进来的流量不收费。往外发的流量我在本机没算清楚，本机统计里混着容器之间的内部流量，要在实验阶段实测（见第 4 节）。所以优先选**不限流量**的套餐。

## 2. 买哪家：价格对比

都选北京地域（千问的接口在北京）。

| 选项 | 价格 | 优点 | 缺点 |
|---|---|---|---|
| **阿里云 轻量应用服务器 4核8G（推荐）** | 月付约 ¥220；新用户年付约 ¥1159（≈¥97/月）；老用户年付约 ¥1123 | 200M 峰值带宽、**不限流量**；和千问同一家、同一个账号；`aliyun` 命令行能管理 | 不能按小时付费，最少买一个月 |
| 阿里云 ECS 按量付费 4核8G | 按小时计费，估计每小时 ¥1 以内，外加出网流量费；开机前用 `aliyun` 查准 | 随开随删，**用来做实验** | 长期用比轻量贵 |
| 阿里云 ECS 包年（u1 / u2a 4核8G） | 活动价约 ¥900/年起 | 性能稳定 | 带宽另算钱，总价不比轻量便宜 |
| 腾讯云 轻量 4核8G | 首年活动价约 ¥450–880；续费"5.5折起" | 首年可能最便宜 | 有流量上限；换一家又多一个账号；续费价不透明 |
| 华为云 Flexus | 包月约 ¥230–290 | — | 没有优势 |

**建议**：
1. 前 2–3 天先开一台阿里云 ECS 按量付费的机器做实验，预计总共花几十块钱。
2. 实验通过后，如果 2 核 4G 跑得住，就买**阿里云轻量 2核4G**（活动价约 ¥199/年，约 ¥17/月）。跑不住再买**阿里云轻量 4核8G**：月付 ¥220 最贵，买一年约 ¥1159（约 ¥97/月）。
3. 不买三年。

## 3. 最大的坑：国内拉不动 Docker 镜像

- Docker Hub（`python:3.11-slim`、`eclipse-mosquitto`）和 ghcr.io（Frigate）在国内基本拉不下来。
- **只有安装时会碰到**。程序跑起来以后连的是千问、机器人云端这些国内服务；唯一的国外地址是天气 `api.open-meteo.com`，实验时测一下能不能连上。
- **做法：镜像在本机构建好，再传到服务器上**：
  - 本机 `docker save` 打成压缩包，用 `rsync --partial` 传过去（断了能接着传），服务器上 `docker load`。
  - **注意避开限速时段**。北京时间 17:00–24:00（多伦多 04:00–11:00）上传只有约 35 KB/s。大文件放在**多伦多下午到晚上**传（北京后半夜到上午）。第 1 天先测一下实际速度。
  - 要传的东西：assistant 约 1.2 GB、engine 约 1.1 GB、Frigate 换成 CPU 版（比现在的 tensorrt 版小很多）、mosquitto、Whisper 模型 605 MB。
  - 实验机上传过一次，正式机就从实验机复制（都在北京，速度很快），不用再跨境传一遍。
- **备选方案**，实验时顺便试，哪个能用就用哪个：
  - 阿里云 ECS 内部的 Docker Hub 加速器：只支持部分官方镜像，不一定能用。
  - ACR 个人版：免费，只能开一个实例，不保证可用性。
  - 国内高校的 ghcr 镜像站。
- **以后改代码不用重新传镜像**：把代码目录挂进容器，改代码只传几个 `.py` 文件再重启，几秒钟。只有新增 Python 依赖时才要重传 assistant 镜像。

## 4. 实验计划（前 2–3 天）

### 第 0 天：你来做（一次性）
- [ ] 阿里云账号实名认证，充值 ¥100–200。
- [ ] 建一个 RAM 子账号，只给 ECS、轻量服务器（SWAS）、VPC 的权限，生成 AccessKey。
- [ ] 我装好 `aliyun` 命令行以后，**你自己运行 `aliyun configure` 填入密钥**，密钥不经过对话。

### 第 1 天：开机、测网络（我来做，花钱的步骤先跟你确认价格）
- [ ] `aliyun` 查价，然后开 ECS 按量付费 4核8G，北京，Ubuntu 24.04 x86，系统盘 80 GB。
- [ ] 安全组只开 22 端口；只允许密钥登录；在本机 `~/.ssh/config` 里配好别名 `ebo-cn`。
- [ ] 用阿里云自己的镜像源装 Docker 和 compose。
- [ ] 测这些并记下来：
  - 多伦多 → 服务器的上传速度（白天、晚上各测一次）
  - 服务器 → `dashscope.aliyuncs.com` 的延迟
  - 能不能连上 `api.open-meteo.com`
  - 第 3 节的几个备选镜像渠道能不能用
- [ ] 开始传镜像和模型（选不限速的时段）。

### 第 2 天：在云上跑起来（不影响家里正在用的那套）
- [ ] 先只启动 Frigate CPU 版、mosquitto、assistant 做压力测试：用一段录好的视频喂给 Frigate，看 CPU 占用和每次检测耗时；同时测 Whisper small 转一句话要几秒。
- [ ] **两套 Engine 不能同时在线**：两边会用同一个机器人账号抢连接。Engine 只在第 3 天切换时启动。

### 第 3 天：正式切换 + 晚高峰实测
- [ ] 拷数据：`.env`、`data/`（家庭记忆、定时器、人脸库、Engine 配对信息），本机打包，rsync 过去。
- [ ] 确认机器人处于待机（`/health` 返回 `session_state==standby`），**停掉本机整套**，再启动云上整套。
- [ ] **北京时间晚上 17:00–24:00 让家里人实际用**，这是最关键的测试。
- [ ] **回退办法**：本机什么都不删。云上出问题就停云上、本机 `docker compose up -d`，一分钟内恢复。

### 怎样算通过
| 指标 | 标准 |
|---|---|
| 晚高峰 "No transcript within 8s" | 基本为 0（现在会刷屏） |
| 说完话到机器人开口 | 明显比现在快，目标 2 秒左右 |
| CPU | 平时低于 70%，Whisper 转录时短时冲高可以接受 |
| 内存 | 低于 6 GB |
| Frigate | 人体检测正常，跟随、找人转圈都正常 |
| 出网流量 | 记下每天多少 GB，用来确认轻量套餐够不够 |

通过以后：按第 2 节买阿里云轻量（2核4G 或 4核8G），从实验机把镜像和数据复制过去（北京内部，很快），再切一次，然后**删掉实验机**，免得一直扣钱。

## 5. 要改的代码（没开始改）

| 改动 | 文件 | 工作量 |
|---|---|---|
| Frigate 换 CPU 版镜像（tensorrt → 标准 stable，固定 digest），删掉 `deploy` 里的 nvidia 设备 | `docker-compose.yml` | 小 |
| 去掉 `hwaccel_args: preset-nvidia`；检测器在 onnx CPU 和 OpenVINO 之间二选一（实验时比较速度） | `frigate/config.yml` | 小 |
| Engine 对外的端口（8098、8554–8557、8189–8192）全部只绑 `127.0.0.1`，云上不对公网开放 | `docker-compose.yml` | 小 |
| 云上专用设置单独放一个 `docker-compose.cloud.yml`，本机继续用 GPU 版，两边互不影响 | 新文件 | 小 |
| 代码目录挂进容器，改代码不用重新做镜像 | `Dockerfile`、`docker-compose.cloud.yml` | 小 |
| 部署脚本：打包镜像、续传、远程 load、同步代码、重启前检查 standby | `scripts/` | 中 |
| 本机桌面快捷方式改成：先开 SSH 隧道，再打开看板 | 桌面快捷方式 | 小 |

- **看板在云上怎么看**：走 SSH 隧道（`ssh -L 8099:127.0.0.1:8099 ebo-cn`）。WebRTC 实时画面通不过隧道，看板会自动改用"图片流"。如果一定要 WebRTC（低延迟、带声音），只能在安全组里给你当前的 IP 单独开 8189–8192，到时候再定。
- **时区**：家里的逻辑用的是 `EBO_HOME_TIMEZONE=Asia/Shanghai`，与服务器所在地无关。日志时间继续用 Toronto 时间（compose 里 `TZ` 默认值），方便你看。

## 6. 日常运维

- 所有操作都从本机发起：`ssh ebo-cn` 和 `aliyun` 命令行。Claude Code 只在你电脑上运行，服务器上不装（国内用不了）。
- 重新部署前先查 `/health` 是不是 standby，避免打断正在进行的对话。
- 每个月看一眼账单和出网流量；续费前比较一下，划算就换平台再用一次新用户价（镜像都在手里，搬家不难）。
